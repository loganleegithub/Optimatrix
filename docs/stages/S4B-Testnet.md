# S4B-Testnet：新手引导与测试网执行

人类于 2026-10-05（客户端日期）明确批准实施：主网公共数据生成 BTC 20/60 日均线上穿信号，Deribit testnet 私人账户自动下单、撤单和对账；单次成本上限 testnet BTC 权益 1%，UTC 08:00 入场检查。仅本机，无主网私人接口或真实资金交易授权，无 Git 提交/推送。

## 保存和能力边界

在已有未提交 S4A 改动上增量实现。开工时对 99 个研究/回测/策略文件保存校验值于被忽略的 `local/s4b-acceptance/baseline-hashes.json`。不重新初始化、不重置、不覆盖旧原始结果。运行绑定 `strategy_id`、`version_id`、冻结规则哈希、实现哈希和 testnet 账户身份。testnet 运行独立保存，不能通过现有 Greeks 六参数回测入口执行。

首页提供三个候选，趋势规则支持逐项确认和“采用其余当前值”。其余两个候选仅为待实现研究草案。导出 `strategy_spec.md` 从指定版本生成；规则修改创建子版本，工程修改不算策略进化。模型及远端研究预算保持 S4A 原限制，不参与实时循环。

## 确定性执行

- 主网 `BTC-PERPETUAL` 只供信号使用。实测 Deribit 原生 1D 数据以 UTC 08:00 分界；按已批准的 UTC 00:00 规则，连接器使用 24 个连续实际小时观测构造每日 OHLC，保留小时原始结果和派生依据，任何小时缺失/重复均阻塞。
- 默认 61 根完整日线比较前后两天 SMA20/SMA60；每天 UTC 08:00 后最多 60 秒尝试一次，不补单。没有新上穿就保持空仓并记录原因。
- 匹配主网和测试网 BTC inverse Call 经济规格，21—45 天中先取最接近 30 天，再取最接近平值；测试网盘口、元数据、权益和成交决定测试网订单数量、价格和账本。
- 每次限价权利金加双边费用准备金最多占 testnet BTC 权益 1%，且不能超过可用资金。数量向下取整；不足最小量跳过。不加仓，部分成交不补齐。
- 买一价≤实际加权买价×70%、每日趋势转弱或剩余期限≤7天时，使用已核对剩余多头数量发出 reduce_only 限价卖单。触发不等于成交，所有损失都可能超过止损阈值。
- 每 UTC 日最多 4 次新单，其中开仓≤1；每个退出意图≤3 次提交。开仓挂单≤300秒、退出≤60秒；撤单确认与实成交对账之前不能替代。

## 凭据、安全与恢复

只有 testnet 连接器读取本机 0600 凭据文件，令牌只存在内存，不输出认证原文。固定域名、方法白名单、禁止重定向和隐式代理认证、关闭写请求自动重试；不提供生产交易开关。凭据在用户授权下于本机转存，未创建密钥或修改权限；账户专属的转存与安全处理记录保留在被忽略的本地审计材料中。

每轮首先检查 STOP，再核对真实账户、持仓、订单和成交；普通网页 GET 不发起采集。订单意图、计数写前落盘；未知提交、未知撤单、无法核对的外部交易均阻塞。用订单与成交 ID 归属实际账本，不把本地零仓当作真实空仓，也不因 label 查询为空重发。原始响应和逐轮事件保存在被忽略的本地目录。

STOP 为强停止，不自动撤单或平仓；“暂停开仓”继续对账与风险退出。重新启动服务不会恢复交易，需显式对账/恢复。页面告警和循环记录持久化；每个新告警先落盘再尝试 macOS 桌面通知，请求成功仍标“未确认送达”。浏览器通知是另一个可选通道，仅页面打开且权限允许时有效。
