## 接入依据与已确认能力

资料来源是 [Greeks.live 官方回测页](https://backtest.greeks.live/static/)、其当前 [api.js](https://backtest.greeks.live/static/api.js?v=20260923-1)、[events.js](https://backtest.greeks.live/static/events.js?v=20260923-1)、[render.js](https://backtest.greeks.live/static/render.js?v=20260921-3)，以及本次真实任务的完整 `report.txt` 和 CSV。浏览器使用 Chrome，读取已登录页面。网页内部协议并非服务商承诺长期兼容的公开回测 API。

用户提供的 `greeks-live-pro-data-api.md` 及 [官方 Data API 文档](https://backtest.greeks.live/api/docs/data-api.md) 描述 CSV 数据下载接口，不能直接作为网页回测协议。Data API Key 对本次回测元数据接口返回 HTTP 401。经用户另行明确授权，现有网页会话的完整 Authorization 值由 Chrome 可见请求头直接保存到本项目 `.env`；未打印凭据、创建新 Key 或改全局配置。

## BTC 模型账本核对

| 模型现金流 | BTC |
| --- | ---: |
| 开仓权利金支出 | 0.00019309228337764038 |
| 平仓收入 | 0.0002615305630156567 |
| 开仓费用 | 0.000001 |
| 平仓费用 | 0.000001 |
| 重建净盈亏 | **0.00006643827963801632** |
| 服务汇总净盈亏 | 0.00006643827963801635 |

净 BTC = 模型平仓收入 − 模型开仓权利金 − 两次假设费用。没有将 USD 汇总除以期末币价，也没有再次乘数量。原始价值不含费用，重建时扣一次；服务 KPI 已含费用，不从 KPI 再扣。模型权利金回报约 **34.40752705%**（分母为不含费用的模型权利金）；假设初始资金 0.2 BTC 的回报约 **0.03321914%**。0.2 BTC 并非余额，这些百分比不是账户实绩。计算保留 Decimal 字符串，页面百分比仅为约数。

核对仅支持已观察的 `backtest_v20`、BTC inverse、单腿 long call、无对冲的一开一平形状。必须满足同一 lot/leg、数量、行权价、期限、UTC 时序、完整性、币种及费用，且明细价差、每日表和 KPI 相符。CSV 与 JSON 浮点尾差容忍为 `1e-15 BTC`，本次差 `−3e-20 BTC`。不支持的版本、混币、截断、结算或不一致均撤回净值计算，显示“无法可靠重建 BTC 净收益”。这证明模型记录内部一致，并未独立重算 SABR 模型或核对真实交易所资金流水。

## 实现与实际检查

没有增加依赖。`backtest.py` 是小型服务适配器，`btc_accounting.py` 做有限模型账本核对；`app.py` 增加本地回测路由，静态页面独立于行情采集。只有显式点击检查或提交才启动回测工作线程。CSRF、同源校验与固定参数限制阻止网页改写任务；本机服务不暴露公网。

提交前先持久化请求和提交意图，同一固定实验复用已有记录。提交超时不重发，重启不自动重新提交或读取远端。历史文件损坏会阻止新提交。操作系统项目文件锁阻止第二个进程干扰正在运行的记录；不需要删除锁文件，进程退出自动释放。

`market.py` 未知异常仍向页面给出短错误，本地日志仅保留异常类型与文件名、行号、函数栈，不记录异常消息、源码行、局部变量、环境或响应正文。

## 未完成与边界

- 没有真实账户、交易授权、订单、内部研究模型或 OpenAI API；没有策略批准流程、交易引擎、常驻采集服务、开机自启或 S3。
- 没有验证 bid/ask 可成交回测、盘口容量、滑点、账户实际费率、真实结算流水或交易优势。仅两条事件、一天变化不足以评价策略表现，不展示误导性的年化或盈利曲线。
- 没有通用多策略/多币种/到期结算核账。服务字段或版本变化时可能拒绝计量，需要按新证据维护；不会自动改参数或更换研究主线。
- 会话过期需要人类在官方页面续期；未验证长期会话稳定性、全部历史质量、多日连续运行或服务端灾难恢复。中断任务保留 id 与状态，当前没有自动续拉界面；提交结果不明需先核对，不能删除记录后盲目重发。
