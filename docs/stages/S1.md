## 范围与实现

- 从空目录 `/Users/logan/Optimatrix` 开始；初查不是 Git 仓库，初始化本地 `main` 时没有提交或远程仓库。未搜索、复制其他项目工程。本次交付目标为 `https://github.com/loganleegithub/Optimatrix`。
- 仅 Deribit 生产公共 HTTPS：BTC 指数、有效 BTC 币本位期权元数据、最多四个合约的第一档买卖价格和数量。
- Python 3.12.13 / macOS 26.6.2 arm64 / Git 2.50.1。项目 `.venv` 内安装 Flask 3.1.3、Waitress 3.0.2、Requests 2.34.2；完整精确版本见 `requirements.txt`，`pip check` 通过。
- 一个进程、一个采集线程；Waitress 仅绑定 `127.0.0.1`。页面/API 路由只读缓存，浏览器不直接请求 Deribit，不触发采集。
- 每轮完成后等待 15 秒；合约目录约每 300 秒更新；价格源龄/收龄超过 60 秒标过时，目录阈值 660 秒。HTTP 429、JSON-RPC 10028、其他接口错误和超时均显式处理；失败退避 30/60/120/240/300 秒，尊重更长的 `Retry-After`。
- 浏览器每 3 秒读取缓存，单次超时 4 秒，无并发轮询；请求失败即提示不可达，10 秒未确认心跳也不能显示正常。用单调时钟推进行情年龄；切回标签页立即重新确认。电脑休眠和浏览器后台节流可能延迟检测。
- 实时选择最近两个到期日，在各日取离指数最近且同时有 Call/Put 的行权价，最多四个合约；优先距离到期超过一小时。不固定合约名，不形成交易信号。
- 无 `.env` 也可运行；S1 不读取 `.env`、`.netrc` 或环境代理，不发送认证头；TLS 校验开启，禁止重定向，客户端仅允许三个公共方法。
- 启动时只查询本地 Codex CLI 版本与登录状态；2026-09-29 检查为 `0.158.0-alpha.2.1`、CLI 报告 ChatGPT 登录。未读取/展示令牌或登录文件，未验证会话能实际运行模型，未运行内部策略模型任务或接 OpenAI API。

## 产品、单位与官方依据

筛选必须满足：`kind=option`、`instrument_type=reversed`、`is_active=true`、`state=open`、`base_currency=quote_currency=settlement_currency=BTC`、`counter_currency=USD`、`price_index=btc_usd`、`contract_size=1`，有合法 Call/Put 类型、正行权价且 UTC 到期时间在未来。布尔值不能冒充数值。未知或不匹配产品不展示，因此不混入 USDC 线性期权。

| 项目 | 本阶段解释 |
| --- | --- |
| BTC 指数 / 行权价 | USD / BTC |
| Bid / Ask | BTC 权利金 / 1 BTC 标的（本产品每张 1 BTC 标的） |
| Bid / Ask 数量 | API 原始 BTC 标的数量；`contract_size=1` 时与张数数值相同，不是权利金额 |
| 期权源时间 | 订单簿 `result.timestamp`，Unix 毫秒 |
| 指数源时间 | 响应信封 `usOut`，Unix 微秒；接口没有独立指数事件时间，页面明确说明 |
| 接收时间 | 本机接收并解析响应时的 UTC 时间，与源时间分开保存 |
| 到期时间 | 元数据 `expiration_timestamp`，Unix 毫秒；页面同时展示 UTC / Asia/Taipei |

截至检查日期，合约 API 的 `quote_currency` 通用文字描述与 inverse options 专项规格存在泛化歧义；本实现依据**产品专项规格与实际响应字段**，BTC 期权报价币种明确为 BTC。

查阅的官方资料：

- [Inverse Options 产品规格](https://support.deribit.com/hc/en-us/articles/31424939096093-Inverse-Options)、[API size/amount 指引](https://support.deribit.com/hc/en-us/articles/38507223482781-API-guidance)
- [get_instruments](https://docs.deribit.com/api-reference/market-data/public-get_instruments)、[get_index_price](https://docs.deribit.com/api-reference/market-data/public-get_index_price)、[get_order_book](https://docs.deribit.com/api-reference/market-data/public-get_order_book)
- [JSON-RPC 时间字段](https://docs.deribit.com/articles/json-rpc-overview)、[限频](https://docs.deribit.com/articles/rate-limits)、[接口错误](https://docs.deribit.com/articles/errors)
- [Flask / Waitress 本地部署](https://flask.palletsprojects.com/en/stable/deploying/waitress/)、[Requests 超时](https://requests.readthedocs.io/en/stable/user/advanced/#timeouts)
